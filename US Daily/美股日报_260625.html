主线五 · 软件 / SaaS / 互联网 / IT 服务 / 中概（逆势走弱）：成长内部风格轮动，资金出逃高估值软件

6/25 半导体 / cyclical 大涨日（SOX +3.9%），高估值软件成长却全线承压——本质是成长板块内部资金从"定性 AI 受益"的软件估值切向"硬件直接受益"的半导体实物资产。非基本面崩溃，是风格轮动。Bear Logic 适用：拥挤的 SaaS 估值面临挤出压力，AI 货币化进度验证滞后于半导体的确定性 capex 数字。
牛熊逻辑闸门 本主线整体处于 Bear Logic（防守 / 压力观察）。行业方向不是"SaaS 基本面崩"——企业 IT 支出周期仍健康，多数公司无当日财报利空。压力来自 风格轮动：市场同日将增量资金配入半导体（SOX +3.9% = 有 capex 数字背书的硬件 AI 受益）而非软件（AI 货币化依赖 NRR 复苏、变现节点模糊）。子分类差异明显——IT 服务 / BPO（CTSH / CNXC）叠加 AI 替代叙事、中概（BABA / TCOM / GDS）叠加中国消费恢复疑虑，两者跌幅更深；逆势涨的 FTNT / CHYM / OPFI 各有独立催化，不属于风格轮动范畴。Bull Logic 观察前提：软件 NRR 企稳（≥115% 或 RPO 加速）、IT 服务订单同比转正、中概消费数据修复——三条路任一有硬证据再讨论切换。

本日关键变化·无集中财报或行业催化；下行主因是 成长板块内部风格切换——SOX 同日 +3.9% 吸走动量资金，软件 / SaaS 相对承压幅度达 8-13pp；CTSH / CNXC / DUOL 个别承压叠加 AI 替代叙事（AI 正在压缩传统 IT 外包 / BPO 服务量、语言学习 App 潜在用户池）；中概 TCOM / GDS 叠加中国消费与数据中心审慎情绪；逆势涨的 FTNT（网络安全防御支出韧性）、CHYM（neobank 独立催化）、OPFI（消费信贷逆周期弹性）均有自身逻辑，不受轮动拖累。
