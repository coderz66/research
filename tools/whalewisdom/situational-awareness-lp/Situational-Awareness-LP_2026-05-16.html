Q4 2024 → Q1 2025 · 策略重构

首份 13F 以 MRVL (18.76%) + VRT (17.76%) 为核心（AI 半导体 + 数据中心电源），附 VST、TLN、CEG 构成 AI Power 矩阵，$255M 建仓。

Q1 2025 完全重构：清仓 MRVL、VRT，将 45.7% 集中于 INTC CALL，同步新建 CRWV、APLD、IREN、CORZ、EQT 等 AI 基础设施矩阵，AUM 升至 $1.01B (+296%)。INTC CALL 大仓体现对英特尔 AI 芯片/代工催化的短周期押注，此后 4 个季度持仓未动，成为全局 anchor 仓位。

Q2 2025 · 对冲结构上线 + AUM 翻倍

新增 SMH PUT 至第一大持仓 (26.85%)，首次引入空头工具，形成"做多英特尔 / 做空半导体指数"利差结构——判断的是行业内部分化，而非单一方向押注。

清仓 MOD、ONTO、CRWV、TLN；集中加码 AVGO (+70%)、CORZ (+77%)、EQT (+117%)、VST (+59%)。AUM $1.01B → $2.12B (+110%)。

Q3 2025 · SMH 对冲解除 + CRWV 三腿集中

SMH PUT 清仓，宽泛半导体空头对冲全面撤除，AVGO / CEG 同步清仓。取而代之的是 CRWV 三腿结构：股票 (13.61%) + CALL (7.65%) + PUT (5.84%) = 27.10%，形成"做多 CRWV 波动率 + 锁定下行"的立体持仓。

新增 NVDA PUT 作为特定对冲——同时持有 CRWV 多仓，暗示"CoreWeave 替代 Hyperscaler 算力"叙事。首次出现 DEBT 工具（CIPH/LUME/BLOO/WEST 可转换票据），显示私募一级市场获取渠道。AUM $2.12B → $4.14B (+95%)。

Q4 2025 · 能源叙事重塑：BE 登顶

BE (Bloom Energy) 成为第一大持仓 (15.87%, $876M)，同步新增 BE CALL，燃料电池/氢能取代核电/天然气成为新能源核心仓。NVDA PUT 与 CRWV PUT 全部清仓，对冲结构收缩，组合整体转向做多。

LITE (Lumentum) 新建 8.68%，AI 数据中心光互联组件入场。加密算力矩阵持续扩张：新增 CIFR、CLSK、KEEL，叠加存量 CORZ/IREN/HUT/APLD，比特币矿 + HPC 双模成为第二大主题集群。新建 INFY PUT，对 AI 颠覆 IT 外包服务商的定向看跌。AUM $4.14B → $5.51B (+33%)。

Q1 2026 · 大规模半导体看跌 + 现货 box 结构

AUM 从 $5.51B 跃至 $13.67B (+148%)，单季增量 $8.16B。配置发生根本转向：前 5 大仓位全部是半导体 PUT——SMH PUT 14.94% + NVDA PUT 11.47% + ORCL PUT 7.84% + AVGO PUT 7.36% + AMD PUT 7.09%，合计 48.7% / $6.66B。叠加 TSM PUT (3.91%) + ASML PUT (3.61%) + MU PUT (4.27%) + INTC PUT (1.16%)，半导体 PUT 总暴露达 $8.04B / 61.6%。

多只 ticker 同时持有现货 + PUT 形成 box 结构（SMH/MU/TSM/AMD/ASML/INTC/NVDA 均有现货小仓 + PUT 大仓），同时 MU 与 TSM 还各持 CALL——读作"做空整体板块、做多个别窗口、保留无限上行"的复合结构，而不是单向看空。

INTC CALL（13.54%、跨 5 个季度未动的 anchor 仓位）整体清仓，同步建立 INTC PUT，立场 180° 反转。Bloom Energy (BE) 从 #1 减仓至 #6（15.87% → 6.42%），CRWV CALL 从 14.04% 砍至 1.03%，能源/算力做多敞口主动收缩。CIFR / EQT / EQT CALL / COHR / KRC / HUT / LBRT 清仓共 8 只。

贯穿主题：AI Power + 算力基础设施 → 半导体高点防御

Q4'24–Q4'25 的底层叙事是数据中心电力需求爆发，发电侧路径持续演进（VST→CEG→EQT→BE），算力侧 CORZ/IREN/APLD/HUT 持仓未断。Q1 2026 叙事转向：半导体行业的周期顶端定价（前 5 PUT 标的全部是 AI 算力链龙头），暗示对"AI capex 顶 / 供给反转"的对冲准备。

CRWV (CoreWeave) 是 AI 算力需求侧代理：Q1 建仓 → Q2 清仓 → Q3–Q4 大规模回归并构建三腿结构 → Q1 2026 把 CRWV CALL 砍掉 83%，留存 CRWV 现货 4.07%，结构由"激进多头杠杆"切回"中性持有"。
